REPRODUCING THE EMPIRICAL PERU RELEASE

Published harmonization method: empirical-positive-pair-v1.1.
Python 3.13 was used. Full physical observation-coverage correction is not complete.

Keep the original four FIRMS ZIP files in a private directory: MODIS, Suomi-NPP,
NOAA-20 and NOAA-21. Preparation preserves the downloads and records their hashes.
Reprocessing already downloaded CSV files does not require Earthdata login.

From the repository root, with an isolated environment:
  python -m pip install -r pipeline/requirements.txt
  python pipeline/bootstrap_inputs.py --zip-folder ORIGINAL_ZIP_DIRECTORY --artifacts ARTIFACTS_DIRECTORY
  python pipeline/run_pipeline.py --artifacts ARTIFACTS_DIRECTORY --workers 8

bootstrap_inputs.py obtains generalized official MINAM geometry and refines two
departments. Public source data can change. Original hashes and metadata are
recorded in the reports; a later download is not guaranteed to be byte-identical.
Boundary assignment depends on geometric detail.

The temporal protocol remains fixed. Repeating an analysis on changed inputs
does not create a previously unseen test set. Report it as a new data snapshot
and do not select variants from final-period performance.

API setup:
  python -m pip install -r api/requirements.txt
  python api/load_history.py --source ARTIFACTS_DIRECTORY/23_demo_historica --out api/history.sqlite
  python -m uvicorn api:app --app-dir api --host 127.0.0.1 --port 8000

For the bundled snapshot, use python api/restaurar_snapshot.py instead of rebuilding.
The historical API can operate without the optional legacy firms.sqlite.
Check /v1/empirical/metadata rather than interpreting database_available alone.

Queries:
  /v1/empirical/series?start=2000-11-06&end=2026-07-27&limit=1000
  /v1/empirical/cells?bbox=-76,-10,-74,-8&limit=1000
  /v1/empirical/metadata
Add instrument=MODIS or instrument=VIIRS, region_id or a valid cell_id as needed.
Follow pagination.next_offset until null. end is exclusive.

MODIS covers 2000-11-06 through 2026-07-26; VIIRS covers 2012-02-06 through
2026-07-26. Earlier VIIRS values remain unavailable. Platforms from the same
instrument are not summed. Calibration bands do not cover every missed fire.
/v1/series remains gated for the full observation-coverage product.

Legacy cell forecast:
  /v1/forecasts?limit=100
This fixed 16–22 November 2026 experiment estimates a weekly record in a 10 km
cell using historical activity and seasonality. It is distinct from the regional
episode-proxy model and does not use recent November weather. Its unfavorable
2025 comparison with climatology is retained in the evaluation.

Regional episode-proxy experiment:
  python -m pip install -r pipeline/requirements-risk.txt
  python pipeline/train_regional_risk.py --help
  python pipeline/generate_regional_outlook.py --help
The required original training, weather and NRT artifacts remain outside Git.
See docs/RESULTADOS_MODELO_EXPERIMENTAL.md and docs/PILOTO_PRONOSTICOS.md.
A renamed target requires its own labels, fitting and evaluation.

Checks:
  python -m unittest discover -s pipeline -p test_calibration.py -v
  python -m unittest discover -s api -p 'test*.py' -v

Executed notebooks summarize prepared artifacts rather than retraining in every
cell. Re-execution requires the corresponding artifacts and dependencies.
Set FIRMS_ARTIFACTS_DIR to the original artifact directory where required.

Uncertainty revision v1.1 corrects the bootstrap time unit from microseconds to
nanoseconds. The v1 bands are withdrawn. There are 237 training blocks and five
bridge blocks with 100 replicates. Central parameters and forecast features
were conserved within 1e-12. See reports/empirical/uncertainty_correction.json.

Official registry comparison:
  python validacion/registro_minam/download_registry.py --out ARTIFACTS_DIRECTORY/27_contraste_MINAM
  python validacion/registro_minam/match_registry.py --artifacts ARTIFACTS_DIRECTORY --out ARTIFACTS_DIRECTORY/27_contraste_MINAM

Reloading history.sqlite adds the comparison to /v1/validation.
The web catalog is rebuilt with pipeline/build_validation_catalog.py.
Matches are historical associations, not proven sensor-omission rates.

FRP research is under research/frp_operator and notebooks/11_limites_deteccion.ipynb.
It is not enabled as a production count correction. The published operator's
table/text discrepancy and A0=0 assumption remain documented.

Sources: NASA FIRMS, official MINAM geometry, and Sofiev and Kouznetsov (2026):
