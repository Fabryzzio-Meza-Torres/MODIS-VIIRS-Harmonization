PUBLISHED DERIVED DATA — PERU — EMPIRICAL RELEASE 1.1

national_series.csv: two national weekly series, starting 2000-11-06.
The last week starts 2026-07-20 and ends 2026-07-26.
VIIRS begins 2012-02-06; earlier VIIRS values remain unavailable.
MODIS has 10 unavailable weeks.

cell_series.csv.gz: comparable counts by cell, week and instrument.
all_platform_calibrations.csv.gz: supplementary five-platform estimates;
do not sum them to replace the two principal instrument series.
platform_selection.csv: platform selected per instrument and week.
cells.csv and peru.geojson: grid and generalized reference boundary.
regional_series.csv.gz, region_cells.csv and regions.geojson: department queries.
forecast_cells.csv.gz and forecast_activity_features.csv.gz: legacy fixed-horizon
cell experiment for 16–22 November 2026, not the newer regional forecast.

history.sqlite.gz: compressed read-only API snapshot, with no credentials.
manifest.json: published dataset sizes and SHA-256 hashes.
regional_outlook.json and its manifest: versioned regional episode-proxy forecast.

From the repository root:
  python -m pip install -r api/requirements.txt
  python api/restaurar_snapshot.py
  python -m uvicorn api:app --app-dir api --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000/docs. Restoration checks hashes and SQLite integrity.
It does not replace a different database unless --replace is explicitly supplied.
Published ZIP releases already contain the restored database.

Use /v1/empirical/series for the historical comparison.
/v1/series remains reserved for the full observation-coverage correction.
coverage_corrected=false means that recovery of all historical fires is not claimed.
Forecasts concern satellite records or episode proxies, not verified ignitions.

Documentation: docs/API.md, docs/METODOLOGIA.md and api/REGIONES_Y_FECHAS.txt.
Historical source records and release archives retain their original content.
