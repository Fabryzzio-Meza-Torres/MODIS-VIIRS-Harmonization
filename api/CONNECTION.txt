READ-ONLY SERIES AND FORECAST API

Run from the repository root with Python 3.13:
  python -m pip install -r api/requirements.txt
  python api/restaurar_snapshot.py
  python -m uvicorn api:app --app-dir api --host 127.0.0.1 --port 8000

Interactive reference: http://127.0.0.1:8000/docs
OpenAPI schema: http://127.0.0.1:8000/openapi.json
Historical viewer: http://127.0.0.1:8000/visor/

Published historical routes:
  GET /v1/empirical/metadata
  GET /v1/empirical/series?region_id=08&start=2023-08-07&end=2023-08-14
  GET /v1/empirical/cells?limit=100
  GET /v1/regions
  GET /v1/validation

The empirical series contains comparable reported counts, not independent fire counts.
coverage_corrected remains false. Missing estimates remain null.

Historical dates use UTC weeks starting on Monday. The end parameter is exclusive.
Follow pagination.next_offset until null. The maximum page size is 1,000.
See REGIONS_AND_DATES.txt for geographic queries and arbitrary calendar ranges.

Regional episode-proxy prototype:
  GET /v1/fire-risk/metadata
  GET /v1/fire-risk/outlook?region_id=08
  GET /v1/fire-risk?region_id=08&target_week_start=2026-11-16

That prototype concerns newly detected episodes, not verified physical ignitions.
Use its metadata to check the issue time, available weeks, target and expiry.
Expired or unsupported forecasts must not be displayed as zero.

The older /v1/forecasts route serves a separate fixed-horizon cell experiment.
Do not use it as a replacement for the regional product.
The /v1/series route remains reserved for the full coverage-corrected product.
It can return 503 until that product is validated and published.

Configuration:
  FIRMS_HISTORY_DB: absolute path to the historical SQLite snapshot.
  FIRMS_API_DB: optional legacy database; its absence does not disable the historical snapshot.
  FIRMS_CORS_ORIGINS: comma-separated origins; public GET requests default to *.

The API reads precomputed artifacts and does not train per request.
No Earthdata or Google Maps credentials are embedded in the service.
For the current contract and deployment status, see docs/API.md.
