REGIONAL AND CALENDAR QUERIES

The catalog contains Peru's 24 departments and Callao, identified by two-digit
IDDPTO codes. For example, 08 is Cusco. Historical regional queries do not imply
independent forecasts for provinces, districts or postal addresses.

1. List departments:
   GET /v1/regions
   Response: metadata, data[{region_id,name,bbox}], pagination.

2. Locate a WGS84 coordinate:
   GET /v1/regions/locate?latitude=-13.5319&longitude=-71.9675
   Returns Cusco (08). An R-tree selects candidates, followed by an exact polygon
   test. Shared-boundary matches are reported; the lowest IDDPTO is the deterministic
   tie-break. MINAM boundaries are generalized and are not cadastral geometry.

3. Compare both instruments in a department:
   GET /v1/empirical/series?region_id=08&start=2023-08-07&end=2023-09-04
   metadata.region identifies the department. Without region_id or cell_id,
   the historical endpoint returns the national series. region_id and cell_id
   cannot be combined. instrument=MODIS or instrument=VIIRS selects one line.

4. Calendar selection:
   week_selection=starts_within selects weeks whose Monday is in [start,end).
   week_selection=overlap selects complete weeks that intersect the interval:
   GET /v1/empirical/series?region_id=08&start=2023-08-10&end=2023-08-17&week_selection=overlap
   This returns totals for the weeks beginning on 7 and 14 August. It does not
   allocate weekly counts proportionally to individual days.
   effective_week_start and effective_end_exclusive report the actual support.
   An inclusive end date in a UI must be advanced by one day before the HTTP query.

5. Geometry and cells:
   GET /v1/regions/geometry
   GET /v1/regions/08/geometry
   GET /v1/empirical/cells?region_id=08&limit=1000
   GET /v1/empirical/cells?region_id=08&bbox=-73,-15,-70,-12&limit=1000
   bbox is west,south,east,north. Cell-center queries combine R-tree candidates
   with exact coordinate checks. Regional cell membership uses positive-area
   intersections, so a boundary cell may belong to more than one department.

6. Count assignment:
   Original selected-platform detections were classified against the same MINAM
   department polygons used by the national domain. Counts were not assigned by
   the center of an entire 10 km cell. All 1,322,019 selected detections were assigned
   once; 66 multi-polygon cases used the documented tie-break.
   National counts and estimates were conserved across the regional partition.
   Regional bands use the shared calibration-factor uncertainty; cell bands were
   not added as if independent. The method remains empirical-positive-pair-v1.1.

7. Indices:
   region_spatial_index: SQLite R-tree for department bounds.
   cell_spatial_index: SQLite R-tree for cell-center bounding-box queries.
   regional_series key: (region_id,week_start_utc,instrument).
   regional_instrument_time index: (region_id,instrument,week_start_utc).
   Spatial indices find candidates; B-tree indices resolve instrument/time queries.

8. Forecast scope:
   GET /v1/fire-risk/metadata documents the regional episode-proxy prototype.
   Its probabilities apply to whole departments and specified published weeks.
   The older GET /v1/forecasts?region_id=08&limit=10 is a distinct fixed-horizon
   cell experiment for 16–22 November 2026. Filtering does not retrain either model.

9. Local reconstruction:
   python pipeline/build_regions.py --artifacts ARTIFACTS_DIRECTORY --out ARTIFACTS_DIRECTORY/31_consultas_regionales
   python api/add_regions.py --database api/history.sqlite --assets ARTIFACTS_DIRECTORY/31_consultas_regionales
   The update checks conservation and integrity before atomic replacement.
   On failure, the previous snapshot remains available.
   load_history.py also accepts --regional-assets.

The compressed data/history.sqlite.gz includes the published regional indices.
Restore with python api/restore_snapshot.py. Review any differing existing
database before using --replace. The API viewer is at /visor/; reusable client
functions are in api/client.js. See docs/API.md for the current release.
